## 课程修读与避坑指南（学长实战经验）

### 1. 教师考勤与平时表现（重中之重）
- 李佳芮老师上课教学严谨，对考勤抓得较为严格；
- **定期纸质点名**：老师经常会在上课初始阶段拿出纸质名单进行点名考勤，平时考勤记录直接与平时分紧密挂钩；
- **课堂互动加分**：
  - 理论课上老师会经常抛出控制理论问题互动提问，主动起立答对的同学会直接记平时分加分；
  - **结课专属加分机会**：最后一节复习答疑课上，老师通常会专门安排提问环节，这是挽救或拉满平时成绩的关键机会，建议提前准备好教材概念积极争取。

### 2. 实验课与机房电脑避坑
- **实验地点**：实验安排在物流工程学院机房开展；
- **设备情况与建议**：机房台式机较为陈旧，部分机器开机和运行 MATLAB / Simulink 较为卡顿甚至卡死；**强烈建议自带笔记本电脑**进行现场实验与算法编写调试；
- **实验报告考核**：实验课结束后，需对照实验指导书要求撰写并提交完整的实验报告（本仓库收录了 2 份已完成的完整实验报告供格式与仿真波形参考）。

### 3. 期末考试与复习建议
- **闭卷纸质笔试**：考试为闭卷纸面考试，不同年级考题形式可能微调（例如有的年级多题选答），但核心考点高度稳定；
- **纯背书为主**：
  - 简答题占比较大，基本属于**纯背诵考点**（本仓库在 `notes/` 目录下收录了按章节全面整理的简答题必背题库）；
  - 考前只要把简答题汇编背透，结合最小拍 7 步法计算与数字 PID 算法推导，几天时间集中刷题即可稳拿高分。
