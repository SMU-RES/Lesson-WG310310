第一章：计算机控制系统概述

【高权重修订】课堂题 1-1：计算机控制系统的组成有哪些？ 参考答案：计算机控制系统主要由
硬件系统和软件系统组成。
1. 硬件系统：包括主机、通用 I/O 设备、过程 I/O 设备和被控对象。主机完成运算、逻辑判断和
控制决策；通用 I/O 设备用于人机交互与信息输入输出；过程 I/O 设备完成计算机与现场对
象之间的信号转换；被控对象是控制系统直接作用的生产过程或设备。
2. 软件系统：包括系统软件和应用软件。系统软件支持计算机运行与资源管理；应用软件实现数
据采集、控制算法、显示报警、自诊断和管理功能。

【高权重修订】课堂题 1-2：计算机控制系统的主要特点有哪些？ 参考答案：
1. 可以实现模拟仪表的功能，便于监视与操作。
2. 采用分时工作方式，可同时控制多个回路，并实现直接数字控制、监督控制、顺序控制等多种
功能。
3. 可实现模拟控制难以完成的先进复杂控制算法，对复杂被控对象进行有效控制。
4. 系统调试与参数整定灵活方便。
5. 可实现工业生产与经营管理、控制的一体化，大幅提升企业综合自动化水平。
6. 采用控制网络技术，用一根电缆连接现场设备与控制器，构成网络化控制系统，实现现场监测、
控制和远程传输等功能。
7. 可实现复杂系统的智能监控，在异常时及时判断、采取措施、分析故障原因并给出指导，缩短
维修和排故时间，提高系统安全性与工作效率。

【高权重修订】课堂题 1-3：计算机控制系统按功能及结构划分可以分为哪几类？每类优缺点如何？
参考答案：
1. 直接数字控制系统（DDC）
• 优点：灵活性大，可靠性高，价格便宜；可对多个回路进行数字控制；改变控制算法和程
序即可实现复杂控制。
• 缺点：主机故障会影响多个控制回路，存在集中风险。
2. 计算机监督控制系统（SCC）
• 优点：可根据被控对象工况和数学模型进行优化分析计算，产生最优设定值送给 DDC 系
统执行。
• 缺点：系统结构较复杂，对上位机、下位机及通信配合要求较高。

3. 集散控制系统（DCS）
• 优点：适合大系统或复杂生产过程控制，易实现复杂控制；积木式结构，组态灵活，易于
扩展；采用 CRT 显示和智能操作，监视操作方便。
• 缺点：不同厂家 DCS 常采用封闭专用通信网络，难以实现网络互连和信息共享，属于封
闭专用、不可互操作的系统。
4. 现场总线控制系统（FCS）
• 优点：开放、全数字化、双向、多站通信，具有良好的开放性、互操作性与互用性。
• 缺点：现场总线标准和产品较多，互操作优势难以充分发挥。
5. 工业以太网控制系统
• 优点：采用公开标准和协议，开放性强；平台无关，可选择不同厂家、不同类型的设备和
服务；可提供 E-mail、WWW、FTP 等多种信息服务；图形用户界面统一友好，操作简
单易学；信息传递快速、准确；易于实现多现场总线集成和多系统集成。
• 缺点：用于强实时控制时仍需解决确定性、工业现场适应性和安全性等问题。

【高权重修订】课堂题 1-4：控制网络与信息网络各有什么作用？两者有什么区别，各适用于何种
场合？ 参考答案：
1. 控制网络：用于连接和管理自动化系统中的控制设备、传感器和执行机构，实现对工业设备的
实时监控、数据采集和远程控制。核心要求是实时性、稳定性、可靠性和安全性，适用于工业
自动化、制造业、交通运输、能源系统等需要实时监控控制的工程场景。
2. 信息网络：用于数据交换、通信和资源共享，支持信息的传输、存储、处理和检索。其重点是
通信速度、数据安全、信息共享和可扩展性，适用于互联网、局域网、广域网、企业内部通信、
远程办公、互联网应用及各类数据交换共享场景。
3. 主要区别：控制网络侧重工业自动化和实时控制，强调实时性与稳定性；信息网络侧重通信和
信息共享，强调数据交换与资源共享。

【高权重修订】课堂题 1-5：计算机控制系统的发展趋势表现在哪几个方面？ 参考答案：
1. 网络化控制：通过现场总线、工业以太网和网络化控制系统实现设备互联、数据共享和远程控
制。
2. 智能型控制：引入智能算法、专家系统、自诊断和自适应功能，提高复杂系统的控制能力。
3. 综合型控制：将底层控制、生产过程监控和经营管理集成，实现生产与管理一体化。


【原汇编保留】例题/思考题 1-1：简述计算机控制系统的控制过程。 参考答案：
1. 实时采集：计算机在采样周期内，通过传感器和 A/D 转换通道，定时获取被控对象的模拟状
态量并转化为数字量。
2. 实时处理：计算机按照预定的控制算法，将采集值与给定值进行比较计算，决策出当前的控制

3. 实时输出：计算机通过 D/A 转换通道将数字控制量变为模拟信号，发送给执行机构，驱动被
控对象执行预期动作。
上述过程在计算机控制下周而复始地进行，使系统满足预定控制要求。



第二章：计算机控制系统的信号分析与处理

【高权重修订】课堂题 2-6：简述模拟量输入通道各组成部分的作用。 参考答案：
1. 信号调理电路：将传感器或变送器输出的微弱电压信号经放大后变换为标准电压信号；对电流
信号，先通过 I/V 变换电路转换为标准电压信号，再经滤波后送入 A/D 转换器。
2. 多路开关：用于切换多路模拟电压信号，实现分时采集。
3. 前置放大器：将模拟小信号放大到 A/D 转换器的量程范围内。
4. 采样保持电路：在 A/D 转换期间保持输入信号不变，以保证转换精度。
5. A/D 转换器：将模拟量转换为数字量，是模拟量输入通道的核心部件。

【高权重新增】课堂题 2-7：A/D 转换器的功能是什么？可以分为哪几类？ 参考答案：A/D 转
换器是将连续变化的模拟信号转换为数字信号的装置，是模拟系统与计算机之间的接口部件。主要
分为三类：
1. 计数型 A/D 转换器。
2. 双积分型 A/D 转换器。
3. 逐位反馈型 A/D 转换器。

【高权重新增】课堂题 2-8：D/A 转换器的功能是什么？由哪几部分组成？其转换方式有哪几类？
参考答案：
1. 功能：D/A 转换器是将数字量转换为模拟量的装置。
2. 组成：主要由基准电压、模拟开关、电阻网络和运算放大器构成。
3. 转换方式：主要有并行转换和串行转换两种。

【高权重修订】课堂题 2-9：什么是香农采样定理？采样周期选取的一般原则是什么？ 参考答案：
1. 香农采样定理：若连续信号 f (t) 的频谱在 |ω| > ωm 处为零，且采样频率 ωs 至少为信号最高
频率 ωm 的 2 倍，则 f (t) 可由其采样序列 f (kT ) 唯一且无失真地恢复。
2. 采样周期选取原则：应综合考虑对象的动态特性、扰动信号影响、控制品质要求、控制算法要
求、计算机及 A/D、D/A 转换器性能、执行机构响应速度以及控制回路数量。

【高权重修订】课堂题 5-12：简述 PID 调节器中比例系数、积分系数和微分系数的变化对闭环系
统控制性能的影响。 参考答案：
1. 比例系数 Kp
• 动态性能：Kp 加大，系统响应速度加快；但 Kp 偏大时，振荡次数增多，调节时间加长。
Kp 太小，响应速度缓慢。
• 稳态性能：若控制器无积分环节，加大 Kp 可减小稳态误差，但不能消除稳态误差。
2. 积分系数 KI
• 动态性能：积分控制通常影响系统稳定性。KI 太大，系统可能不稳定，振荡次数增多；KI
太小，积分作用削弱；KI 适当时，过渡过程较理想。
• 稳态性能：积分控制有助于消除稳态误差，提高控制精度；但 KI 太小，积分作用弱，不
能减小余差。
3. 微分系数 KD
• 动态性能：增加微分作用可改善动态特性，如减少超调量、缩短调节时间；但微分作用可
能放大系统噪声，降低抗干扰能力。

• 稳态性能：微分环节能在误差出现或变化瞬间，按偏差变化趋势进行控制，在偏差变大前
引入早期修正信号，加快系统动作速度，减小调节时间。

【高权重修订】课堂题 5-13：在数字 PID 控制中，选择采样周期 T 应该根据什么原则？ 参考答
案：数字 PID 控制中，采样周期 T 的选择应满足香农采样定理，同时遵循采样周期选取的一般原

1. 被控对象的动态特性。
2. 扰动信号的影响。
3. 控制品质要求。
4. 控制算法要求。
5. 计算机及 A/D、D/A 转换器性能。
6. 执行机构响应速度。
7. 控制回路数量。

【高权重修订】课堂题 5-14：什么叫积分饱和作用？它是怎样引起的？可采取什么办法消除？ 参
考答案：
1. 定义：执行机构已达极限位置但仍无法消除偏差时，积分作用持续累积，使 PID 控制器输出继
续变化，而执行机构已无相应动作，导致控制失效，这种现象称为积分饱和。
2. 引起原因
(a) 偏差突变：偏差产生跳变时，位置型 PID 算式的输出急剧增大或减小，可能超出执行机构
上下限，而执行机构只能停留在限位处。
(b) 长时间偏差存在：系统输出需要较长时间才能达到给定值，此期间积分项积累了很大的数
值。
(c) 反向调节困难：当系统输出超过给定值、偏差反向时，由于积分累积值过大，控制量需要
很长时间才能脱离饱和区，导致大幅超调甚至不稳定。
3. 改进方法：可采用积分分离 PID 控制算法、变速积分 PID 控制算法和抗积分饱和机制。

比例系数 Kp 相应确定。

2. 加入积分环节（PI）：若比例调节下系统稳态误差太大，则加入积分环节。先将第一步整定的
比例系数略为缩小（如取原值的 0.8 倍）
，再将积分时间常数 TI 置为较大值并连续减小，以在
保持动态性能的前提下消除稳态误差。该步骤可反复进行，根据响应曲线好坏调整 Kp 与 TI 。

：若使用 PI 控制器消除了稳态误差，但动态响应仍不满意，则加入微分

【高权重修订】课堂题 5-16：简述扩充临界比例度法整定 PID 参数的步骤。 参考答案：
1. 选定一个足够短的采样周期。
2. 用比例控制器构成闭环，使数字闭环系统工作；逐渐加大比例系数 Kp ，直到系统发生持续等
幅振荡。对应此时的比例系数为 Kr ，临界振荡周期为 Tr 。
3. 选择控制度在 1.05 ∼ 2.0 之间，根据 Kp 和 Tr 查表得出 PID 控制器参数。
4. 根据查表得到的 PID 参数运行系统。若控制效果不好，可适当减小比例系数 Kp ，重复上一步，
直到获得满意的控制效果。

【高权重新增】课堂题 5-17：简述扩充响应曲线法整定 PID 参数的步骤。 参考答案：
1. 让系统处于开环状态下，将被调量调节到给定值附近并使之稳定下来。
2. 给系统加以阶跃输入，记录被调量的阶跃响应曲线。
3. 在阶跃响应曲线的拐点（即斜率最大的点）处作切线，求得滞后时间 τ 和被控对象时间常数 T ，
然后根据参数设计表求得各参数。

1. 积分分离 PID：设定阈值 ε。当 |e(k)| > ε 时取消积分作用，采用 PD 控制；当 |e(k)| ≤ ε 时
引入积分，采用 PID 控制。这样可避免大偏差阶段积分过度累积，减小超调。
2. 抗积分饱和 PID：当执行机构达到限位而偏差仍存在时，积分项持续累加会造成严重超调和
滞后。抗积分饱和策略是在控制量进入饱和区后，停止同号偏差的积分累加，使控制量尽快脱
离饱和区。

【原汇编保留】例题 5-9：微分先行 PID 控制。 参考答案：微分先行 PID 将微分环节置于反馈通
道中，仅对系统输出 y(t) 进行微分，而不对给定值 r(t) 微分。这样在给定值频繁阶跃变化时，微
分项不会产生大幅冲击信号，系统跟踪更平滑，可避免因给定值突变引起的振荡。



第六章：计算机控制系统的离散化设计

【高权重修订】课堂题 6-18：什么是最小拍系统？最小拍系统有什么不足之处？ 参考答案：
1. 定义：最小拍系统是指在典型输入信号（如阶跃、速度、加速度等）作用下，经过最小有限个
采样周期后，系统输出的稳态误差为零的控制系统。
2. 不足之处
(a) 对输入信号适应性差：按某一种典型输入设计的最小拍控制器，不适用于其他类型输入。
(b) 对系统参数变化敏感：系统参数变化时控制性能下降，鲁棒性较差。
(c) 输出在采样点之间存在纹波，影响控制平滑性。

【高权重修订】课堂题 6-19：大林算法的设计目标是什么？什么是振铃现象和振铃幅度？如何消
除振铃？ 参考答案：
1. 大林算法设计目标：使闭环系统相当于纯滞后加一阶惯性环节，且纯滞后时间与被控对象相同。
2. 振铃现象：数字控制器输出以二分之一采样频率作大幅度衰减振荡。
3. 振铃幅度：控制器在单位阶跃输入作用下，第 0 次输出与第 1 次输出之差。
4. 消除振铃的方法
(a) 将数字控制器中引起振铃的极点用 z = 1 代入替换为常数，以去除该极点；该方法不影响
稳态值，但可能增加超调和调节时间。
(b) 从保证闭环系统特性出发，合适选择采样周期 T 和闭环时间常数 Tr ，使控制器输出避免
产生强烈振铃。

【高权重修订】课堂题 8-23：请对网络化控制系统中传感器到控制器和控制器到执行器的端到端
时延组成和特点进行分析。 参考答案：网络化控制系统中的端到端时延主要包括以下四部分：
1. 发送处理时延 Tsend ：可预测，取决于设备性能。
2. 等待时延 Twait ：最主要且不确定，随网络节点数和数据量的增加而增大。即使在正常工作状
态下，对于采用不同协议的系统，等待时延也会随介质访问控制机制不同而有很大差异。
3. 传输时延 Tts ：确定，由带宽决定，通常较小，可以忽略。
4. 接收处理时延 Trev ：可预测，取决于设备性能。
